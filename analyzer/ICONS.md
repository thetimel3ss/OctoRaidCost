# Bundled artwork

Warcraft item and class artwork belongs to its respective rights holders. These files are bundled so reports do not request remote images while being viewed or printed.

Items: [OctoWoW database](https://octowow.st/db/). Icon names were resolved from each exact item ID, then PNG signatures and dimensions were validated. The 511 catalog IDs map to 396 unique 64×64 images.

Classes: Wowhead/ZAM. Matching class icon paths were unavailable on the Octo database.

The neutral bag and ORC shield/statistics mark are original SVG drawings used by ORC. The tab favicon reuses that shield on a dark background, as SVG with a 32×32 PNG fallback. The bag is decorative and indicates missing artwork, not uncertainty about item identity.
